# Vikas Raj — Personal Portfolio

A modern, responsive personal portfolio website showcasing my projects, technical skills, experience, and contact information.

Built with a focus on clean UI, smooth animations, responsive design, and a premium interactive experience.

## 🚀 Live Website

[Visit Portfolio](https://vikas-tovi.dev)

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern single-page portfolio layout
- Animated navbar with scroll-based behavior
- Responsive mobile navigation and dropdown menu
- Smooth section navigation
- Active navigation link detection
- Animated hero section
- Interactive project cards
- Live project and GitHub links
- Technical skills / tech stack section
- Responsive contact section
- Resume download
- Social media links
- Custom favicon and branding
- Optimized UI for different screen sizes
- Smooth animations and hover interactions
